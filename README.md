# Task 3 - Responsive Quiz & Joke Generator

This project is a part of my internship at *Apex Planet Software Pvt. Ltd.* under the *Web Development domain*.  
It demonstrates my ability to use *HTML, CSS, and JavaScript* to build responsive and interactive web pages.

## Features

- *Interactive Quiz*
  - Multiple choice questions
  - Score tracking
  - Dynamic question loading using JavaScript

- *Joke Generator*
  - Fetches jokes from a public Joke API
  - Includes fallback content if API fails

- *Responsive Design*
  - Fully responsive layout for mobile and desktop
  - Clean UI using Flexbox and media queries

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Fetch API
